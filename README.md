# AI 문제해결 — 웹 에디션

『**AI 문제해결** — AI 에이전트와 함께 문제를 정의하고 직접 만들어 푸는 법』(강영민)의
웹 에디션입니다.

- 서비스 주소: <https://dknife.github.io/AI_ProblemSolving/>
- 원고(LaTeX)는 별도 폴더에서 관리하며, 이 저장소에는 변환된 `docs/`만 올라갑니다.

## 이 책은

전공을 가리지 않는 교양 수업 교재입니다. 코딩이나 컴퓨터 전공 지식이 없는 학생이
자기 전공의 문제를 스스로 풀어내는 역량을 갖추는 것을 목표로 합니다.

- 13개 장 중 **일곱 장이 만들기 전 단계**입니다. 만들기가 쉬워진 만큼 병목이
  *무엇을 만들지 정하는 일*로 옮겨 갔기 때문입니다.
- 결과물은 둘입니다. 주소를 보내면 남이 열어 쓰는 **웹 서비스**(9\~10장)와,
  반복 작업을 대신 해 주는 **파이썬 앱**(11장).
- 모든 실습을 **무료 도구**로, **설치 없이** 완주할 수 있게 설계했습니다.

## 구성

| 부 | 장 |
|---|---|
| I. 문제와 AI | 1 문제를 푸는 방식이 달라졌다 · 2 AI는 어떻게 답을 만드는가 · 3 에이전트: 스스로 일하는 AI |
| II. 문제 정의와 해법 설계 | 4 문제를 찾아내고 정의한다 · 5 문제를 쪼개고 구조를 본다 · 6 해법을 찾고 고른다 · 7 AI와 제대로 대화한다 |
| III. 만들어 해결하기 | 8 만들기 위한 준비 · 9 첫 번째 웹 서비스 만들기 · 10 세상에 내놓기 · 11 파이썬 앱으로 반복을 없앤다 · 12 고치고 다듬는다 |
| IV. 프로젝트 | 13 나의 문제 해결 프로젝트 |
| 부록 | A 무료 AI 도구와 에이전트 · B 문제 해결 프롬프트 사전 · C 자주 만나는 오류와 해결 · D 배포와 공유 안내 |

## 저장소 구조

```
docs/
  index.html            안내 페이지 (손으로 관리)
  editableserver.py     로컬 편집 서버 실행기 (손으로 관리)
  book/
    ch01~ch13.html      본문 (tex2html.py가 생성)
    apxa~apxd.html      부록 (생성)
    front.html          표지·머릿말 (생성)
    references.html     참고문헌 (생성)
    book.css, book.js   웹 조판·인터랙션 (손으로 관리)
    viewer.html         그림 확대 보기 (손으로 관리)
    data/               위젯 자료 (손으로 관리)
      tokens.json       2.1절 다음 낱말 고르기
      tools.json        부록 A 도구 비교표
    img/                그림 (생성·복사)
```

`book.css`, `book.js`, `viewer.html`, `data/*.json`, `index.html`,
`editableserver.py`는 **손으로 관리하는 파일**입니다. 웹 빌드를 다시 돌려도
덮어쓰이지 않습니다.

## 도구 정보 갱신

부록 A의 비교표는 원고가 아니라 `docs/book/data/tools.json`이 만듭니다.
요금과 한도는 자주 바뀌므로 **학기 시작 전에 이 파일만 확인해 고치면** 됩니다.

## 로컬에서 보기

```bash
cd docs && python3 -m http.server 8899   # http://localhost:8899/
```

`file://`로 열면 위젯이 동작하지 않습니다 — `data/*.json`을 읽기 때문입니다.
